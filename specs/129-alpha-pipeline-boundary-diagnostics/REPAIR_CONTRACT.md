# Repair Contract Pointer

The reusable FlowVault ZPK/FVWF baked-text alpha repair contract is maintained
as the standalone repository-level file:

`SPECKIT.md`

Spec 129 remains the evidence and diagnostic record supporting that contract.
The contract is intentionally separate so it can be discovered and followed in
future repair chats without treating the completed diagnostic specification as
a new implementation task.
